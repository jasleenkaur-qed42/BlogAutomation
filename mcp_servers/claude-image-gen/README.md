tool `create_asset`. Copied unmodified from `mcp-server/build/bundle.js` (v1.2.2). To update, copy a newer
`bundle.js` over this one. Started through `mcp_servers/image_gen_server.py`, which loads `GEMINI_API_KEY` from the
project's dotenv file.
